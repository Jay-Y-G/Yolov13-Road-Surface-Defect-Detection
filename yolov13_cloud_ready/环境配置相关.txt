使用anaconda3管理环境
下载：选择对应版本即可（windows为例）
安装向导：Just Me ->安装路径最好选择D盘，纯英文路径 ->全部勾选

显卡驱动
50系显卡都需要12.8以上的的CUDA，对应的cudnn是9.x版本（这里我选择cuda12.9和cudnn9.10.2）
https://developer.nvidia.com/cuda-toolkit-archive
https://developer.nvidia.com/cudnn-archive

nvcc -V显示版本是12.9即可
cudnn的网站选好版本（9.10.2）选择Windows，x86-64，tarball，12，下载压缩包，解压，打开有include，lib，bin三个文件
进入
C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v12.9
替换这三个文件

全局cudnn的安装不影响项目，项目安装pytorch时会自动安装好对应cudnn（torch2.7.0--cudnn9.7.1）

打开anaconda prompt
可以选择更改下载源（中科大源）
conda config --remove-key channels
conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.ustc.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.bfsu.edu.cn/anaconda/cloud/pytorch/
conda config --set show_channel_urls yes
pip config set global.index-url https://mirrors.ustc.edu.cn/pypi/web/simple
也能不更改

创建环境
conda create -n yolov13 python=3.11
进入环境
conda activate yolov13

第一步：安装torch相关
pip install torch==2.7.0 torchvision==0.22.0 torchaudio==2.7.0 --index-url https://download.pytorch.org/whl/cu128
第二步：安装requirments（最艰难）（已经改好）
pip install -r requirements.txt
第三步：安装flash-attention（已经在文件中）
pip install flash_attn-2.7.0.post2+cu124torch2.4.1cxx11abiFALSE-cp311-cp311-win_amd64.whl

创建标注环境
conda create -n labelimg python=3.8
进入环境
conda activate labelimg
cd进入data文件夹
labelimg JPEGImages classes.txt
即可打开标注
